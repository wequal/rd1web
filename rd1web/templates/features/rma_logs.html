Log Monitoring Tips
  • RMA activities are logged to /var/log/rma/ if available
  • PXE boot events appear in /var/log/pxe/ and system logs
  • System-wide RMA events are recorded in /var/log/syslog
  • Use the refresh button to get the latest log entries
  • Logs older than 30 days may be archived automatically
Search Keywords

Common terms to look for in RMA logs:

  • RMA - RMA activities
  • PXE - Boot events
  • DHCP - Network assignment
  • TFTP - Boot file transfer
  • ERROR - Error conditions
  • FAILED - Failed operations
  • SUCCESS - Successful operations
  • TIMEOUT - Timeout events
