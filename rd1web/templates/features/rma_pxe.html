RMA PXE Manager Help
RMA Information

Base SN: The serial number of the base system being processed for RMA.

RMA Number: The unique identifier assigned to this RMA case for tracking purposes.

MAC Address Format

Enter MAC addresses in any of these formats:

  • aa:bb:cc:dd:ee:ff (colon separated)
  • aa-bb-cc-dd-ee-ff (dash separated)
  • aabbccddeeff (no separators)
Test Types
Generic:

Standard RMA validation tests including hardware diagnostics, memory tests, CPU stress tests, and basic functionality verification.

Coreweave:

Specialized test suite for Coreweave infrastructure including GPU benchmarking, CUDA validation, network performance testing, and cloud-specific hardware checks.

Cooling Types
LC (Liquid Cooling):

For systems equipped with liquid cooling solutions. This selection ensures appropriate thermal management protocols and cooling-specific test parameters are applied during RMA validation.

AC (Air Cooling):

For traditional air-cooled systems using standard thermal management. This is the default cooling type for most standard server configurations.

Available Actions
  • Check: Verify if the specified MAC addresses already have PXE configurations
  • Remove: Delete existing PXE boot configurations for the specified MAC addresses
  • Add (Default): Create new PXE boot configurations with RMA parameters
