Common IPMI Commands
Power Management
  • power status - Check power state
  • power on - Power on system
  • power off - Power off system
  • power reset - Reset system
  • power cycle - Power cycle
System Information
  • fru print - FRU information
  • mc info - BMC information
  • bmc info - BMC details
Monitoring
  • sensor reading - All sensors
  • sensor list - Sensor list
  • sel list - System event log
  • sel clear - Clear event log
Boot Options
  • chassis bootdev pxe - Boot from PXE
  • chassis bootdev disk - Boot from disk
  • chassis bootdev cdrom - Boot from CD
IPMI Tool Help
About IPMI

IPMI (Intelligent Platform Management Interface) allows remote management of server hardware including power control, monitoring, and configuration.

Prerequisites
  • BMC must be configured with network settings
  • Valid username and password for BMC access
  • Network connectivity to BMC interface
Security Notes
  • Use strong passwords for BMC accounts
  • Limit network access to BMC interfaces
  • Monitor BMC access logs regularly
