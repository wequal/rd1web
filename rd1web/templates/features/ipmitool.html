Common IPMI Commands
Power Management
  • power status - Check power state
  • power on - Power on system
  • power off - Power off system
  • power reset - Reset system
  • power cycle - Power cycle
System Information
  • fru print - FRU information
  • mc info - BMC information
  • bmc info - BMC details
Monitoring
  • sensor reading - All sensors
  • sensor list - Sensor list
  • sel list - System event log
  • sel clear - Clear event log
Boot Options
  • chassis bootdev bios - Boot to BIOS
  • chassis bootdev pxe - Boot from PXE
  • chassis bootdev disk - Boot from disk
  • chassis bootdev cdrom - Boot from CD/DVD
  • chassis bootdev none clear-cmos=yes - Clear CMOS
IPMI Management Tool - Help Guide
IPMI Commands

Execute remote IPMI commands on multiple BMCs simultaneously.

Setup Requirements
  • BMC IP Addresses: Enter one IP per line for each target BMC
  • Passwords: Enter passwords in the same order as IP addresses
  • Username: Typically 'ADMIN' or 'root' for most BMCs
  • Network Access: Ensure BMC interfaces are reachable
Quick Commands
  • Power Dropdown: Power Status, Power On/Off, Reset - Control system power state
  • Next Boot Dropdown: Boot to BIOS, PXE, Disk, CD/DVD, Clear CMOS - Set boot device
  • Sensors: View temperature, voltage, and fan readings
  • FRU Info: Display hardware inventory
  • Firmware Info: Get firmware versions via Redfish API
Remote Console
  • KVM: Opens graphical console in new window
  • SOL: Opens serial-over-LAN terminal
  • Both use the first BMC IP and password from your lists
Unique Password Lookup
  • MAC Address Formats: Accepts 7cc25589011f, 7c-c2-55-89-01-1f, or 7c:c2:55:89:01:1f
  • Supermicro API: Queries official Supermicro database for default passwords
  • Automatic Conversion: Normalizes MAC format to lowercase without separators
  • Copy Function: Click copy button to copy password to clipboard
Tips & Troubleshooting
  • Multiple BMCs: Commands execute in parallel for efficiency
  • Connection Issues: Check network connectivity and credentials
