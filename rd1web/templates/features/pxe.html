PXE Boot Manager Help
MAC Address Format

Enter MAC addresses in any of these formats:

  • aa:bb:cc:dd:ee:ff (colon separated)
  • aa-bb-cc-dd-ee-ff (dash separated)
  • aabbccddeeff (no separators)
Test Types
BurnIn Tests:
  • SAT - System Acceptance Test (requires duration)
  • IPERF - Network performance test (requires duration)
  • STRESS - System stress test (requires duration)
  • DCGM - GPU monitoring test
  • FIO - I/O performance test (requires duration)
DC Test:

Tests DC power cycling with specified cycle limit and interval.

AC Test:

Tests AC power cycling using PDU, requires IP address, port numbers, cycle limit, and interval.
