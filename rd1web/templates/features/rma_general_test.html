RMA General TEST Help
RMA Information

System SN: The serial number of the system being processed for RMA.

RMA Number: The unique identifier assigned to this RMA case for tracking purposes.

NIC MAC: The MAC address of the network interface card. You can enter it in various formats:

  • With colons: ac:1f:6b:35:6f:19
  • With dashes: ac-1f-6b-35-6f-19
  • Without separators: ac1f6b356f19
The system will automatically normalize the format.

Available Actions
  • Check: Verify if the specified NIC MAC already has PXE configurations
  • Remove: Delete existing PXE boot configurations for the specified NIC MAC
  • Add (Default): Create new PXE boot configurations with RMA parameters
Tests

This page automatically uses the default test configuration. No manual test selection is required.
